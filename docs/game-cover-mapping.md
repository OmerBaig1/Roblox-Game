# Game cover mapping

Every game in the collection (151, from `ReplicatedStorage.GamePoster.Art`), the real game it parodies, and the file
name to use if a cover image is supplied. In-game names stay the parody names; only the picture would change.

**Status for every row: no cover integrated.** Real box art belongs to each game's publisher, and Roblox's Terms of
Use only allow uploading images you have the rights to, so none were downloaded or uploaded. Rows marked *(check)*
have no single obvious cover.

Reference folder `Games Reference Images` (4 files): Five Nights at Freddy's, Devil May Cry 5 and Fortnite covers,
plus one `.avif` file that could not be opened.
